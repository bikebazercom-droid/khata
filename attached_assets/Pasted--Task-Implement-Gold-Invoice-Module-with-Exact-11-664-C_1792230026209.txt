#### 2. Gold Calculation Logic & Standard Factor (11.664 Grams)
Implement exact gold calculations inside the form state using the following mathematical logic:
- **Conversion Factor:** `1 Vori / Tola = 11.664 grams`.
- **Line Item Formulas:**
  - `Gross Wt. (grams)`: Total weight entered by user.
  - `Purity`: Purity decimal value (e.g., `0.916` for 22K, `0.875` for 21K, `0.750` for 18K, `0.999` for 24K).
  - `Pure Wt. (grams)` = `Gross Wt. × Purity` (rounded to 3 decimal places).
  - `Making Rate & Amt.`: Making charges added per gram or total amount.
  - `Line Total` = `(Pure Wt. × Metal Rate per Gram)` + `Making Amt.`.
- **Summary Calculation Block:**
  - `Total Gross Wt.` = Sum of item Gross Weights.
  - `Total Pure Wt.` = Sum of item Pure Weights.
  - `GOLD VALUE` = `Total Pure Wt. × Metal Rate per Gram`.
  - `Total Amount Before VAT` = `GOLD VALUE + Total Making Charges`.
  - `VAT Amount (5%)` = `Total Amount Before VAT × 0.05`.
  - `Total Amount Including VAT` = `Total Amount Before VAT + VAT Amount - Round Off Discount`.
  - Auto-convert total number to words (e.g., "Forty Six Thousand Eight Hundred...").
